## Key Insights

1. **No existing open-source solution** — perlu build dari nol
2. **Competitors charge $25-99/month** — bisacompetitive dengan harga lebih rendah
3. **Core features needed:**
   - Inventory tracking (buah masuk/keluar)
   - Supplier management
   - Recipe management
   - Sales tracking
   - Waste/spoilage tracking

4. **Tech stack:** Mirip Trading Company (Next.js + FastAPI + PostgreSQL)
