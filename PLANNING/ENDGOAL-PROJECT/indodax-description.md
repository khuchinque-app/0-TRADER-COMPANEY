# INDODAX — Description

## What it is
INDODAX (originally **Bitcoin.co.id**, rebranded later) is Indonesia's **oldest and first cryptocurrency exchange**, founded in **2014** and headquartered in **Jakarta**. It is a privately held, independent company — notable for *not* being owned by a global exchange group. Its main rival Tokocrypto is owned by Binance.

## Business & scale
- **500,000+ registered users**, **500+ cryptocurrencies listed**, ~740–842 employees.
- Revenue estimated at **$250M–$500M/year**, primarily from trading fees.
- Total external funding is small (**$1.1M**, last round Nov 2017) — it has largely self-funded its growth.
- Extra revenue/gamification feature: **DAX Rewards** (launched Aug 2026); ecosystem is otherwise exchange-focused rather than a broad product suite.

## Regulation & compliance
- Regulated by **OJK** (Otoritas Jasa Keuangan) and registered with **Bappebti**.
- Integrated **Chainalysis** for on-chain transaction monitoring and AML/KYC — a core selling point after its security incident.
- Long compliance track record (11+ years) is a key competitive advantage.

## Security history
- **September 2024**: suffered a major security breach with approximately **$20M stolen**. The company recovered, rebuilt its security infrastructure, integrated Chainalysis, and updated protocols. Post-incident security is described as improved.
- Standard protections: Cloudflare DDoS shield, TLS via Cloudflare, 2FA, cold storage.

## Technology
- **PHP-first backend** (PHP API examples are the official ones), with a community-built **Go** library (`go-indodax`); JavaScript/TypeScript on the frontend.
- Hosted on **Google Cloud Platform (GCP)** behind **Cloudflare CDN**.
- **Redis** confirmed for caching/sessions; PostgreSQL/MySQL and a time-series DB inferred.
- DevOps on **Azure DevOps**; monitoring via **New Relic** and **Splunk**; analytics with **Piwik PRO** and **Tableau**; marketing automation via **Marketo**.
- APIs: REST (public + private) and WebSocket, HMAC-SHA512 signed; **Trade API v2** updated Aug 2026. Official docs live in a GitHub repo (**173 stars**, PHP examples only).

## Recent developments (2025–2026)
- **May 2025**: William Sutanto appointed CEO (founder Oscar Darmawan remains a central figure).
- **Jun 2025**: DigiAsia Corp partnership for fiat transfers.
- **Aug 2026**: DAX Rewards launch, Trade API v2 update, and participation in the ETH Genesis "Quantum Leap" forum on quantum-computing threats to blockchain.

## Positioning
A **resilient incumbent**: oldest brand in the market, strong local banking relationships and regulatory experience, but facing a 10x-larger competitor (Tokocrypto/Binance). Seen as a potential **acquisition target** and "recovery play" in the market analysis.
